## 方向一：公式化因子的搜索与进化范式

本方向的共同命题是：如何在巨大的公式空间中系统性地搜索因子。各篇差异集中在搜索算子与结构假设上——生成-预测网络（AlphaForge）、蒙特卡洛树搜索（MCTS-Alpha）、LLM 作为进化算子（EvoAlpha）与进化式特征工程（AlphaQuant）、双链生成-优化（Chain-of-Alpha）、GFlowNets 分布学习（AlphaSAGE）、DAG 全局拓扑（AlphaPROBE）。AlphaQuant 的对象虽是表格特征而非公式化 alpha，但其「数据驱动的 MDP + LLM 进化搜索」与同组工作同构，故归入本方向。

### AlphaForge · AAAI 2025

生成-预测网络挖掘多样化公式化因子库，再以每日动态时序加权组合因子（Factor Timing）；在 CSI 300 / 500 上 IC、RankIC 优于 MLP、LightGBM、XGBoost、GP、RL、DSO 等基线，因子池大小为 10 时性能最优，并已通过实盘验证。

### MCTS-Alpha · AAAI 2026

LLM + 蒙特卡洛树搜索的公式化因子挖掘（Navigating the Alpha Jungle）：节点为候选公式并允许虚拟扩展动作 $a_e$ 多次精炼；Effectiveness、Stability、Turnover、Diversity、Overfitting Risk 五维评估以相对排名替代固定阈值；频繁子树避免（FSA）显式抑制公式同质化，搜索效率与可解释性双优。

### Chain-of-Alpha · arXiv 2508.06312（已撤稿）

**论文**：Chain-of-Alpha: Unleashing the Power of Large Language Models for Alpha Mining in Quantitative Trading。

**背景与问题**：alpha 因子挖掘是量化交易的核心任务，目标是发现能预测资产收益、且独立于系统性市场风险的可解释信号。传统方法依赖人工设计公式或机器学习启发式搜索，效率低、通用性不足、难以全自动化；现有基于 LLM 的方法在自动化程度、通用性和效率上仍有明显局限。Chain-of-Alpha 旨在构建一种新颖、简洁且高效的全自动化公式化 alpha 挖掘系统。

**方法**：双链架构（Dual-Chain Architecture）

- 因子生成链：利用 LLM 仅基于市场数据迭代生成数学公式形式的候选 alpha，全程不依赖人工干预；
- 因子优化链：利用回测反馈与先验优化知识评估、精炼候选因子，并将反馈传回生成链；
- 协同机制：两链以迭代循环工作——生成链提出候选，优化链回测评估，评估结果驱动下一轮生成。闭环设计使系统能在无人工干预下持续生成并优化高质量因子，同时具备良好的可扩展性。

**实验与结论**：

- 实验市场为 A 股真实基准数据；Chain-of-Alpha 在多项评估指标上优于现有基线方法；
- 核心结论：双链架构能有效提升因子生成质量与优化效率，仅利用市场数据和回测反馈即可实现全自动化挖掘。

**关键概念**：

| 概念 | 解释 |
| --- | --- |
| Alpha 因子 | 量化交易中的「预测信号」，即帮助预测股票未来涨跌的数学公式或规则 |
| 公式化 Alpha（Formulaic Alpha） | 用明确数学公式表达的信号（如「收盘价 / 开盘价 × 成交量」），透明、可解释 |
| 双链架构 | 「创意设计师」（生成链）与「严格质检员」（优化链）搭档：设计师不断提出新点子，质检员立即测试并反馈，设计师再根据反馈改进，循环往复 |
| 回测反馈 | 用历史数据检验策略或因子过去的表现，类似用往年高考试题检验复习方法 |
| Chain-of-Alpha | 名称致敬「思维链」（Chain-of-Thought），表示连续推理、逐步优化的 alpha 挖掘链条 |

**优点**：架构简洁清晰，生成与优化分离又协同；完全自动化大幅降低人力成本；在真实 A 股数据上广泛实验并与多个基线对比；方法论影响力大，被 AlphaSAGE、AlphaPROBE、MEME、Hubble 引用为基线。

**局限**：

- 结构感知与探索鲁棒性不足（据 AlphaSAGE 指出）；
- 自动化程度仍有提升空间（据 Hubble 指出）；
- 论文撤回后，部分实现细节与完整实验结果无法公开获取，难以复现。

**后续方向**：引入结构感知机制（如行业关联、图结构）；增强探索多样性与鲁棒性；与强化学习或元学习结合优化反馈机制；融入新闻文本、社交媒体情绪等多源数据；跨市场泛化验证；研究 LLM 生成过程的可解释性。


### AlphaSAGE · arXiv 2509.25055


**论文**：AlphaSAGE: Structure-Aware Alpha Mining via GFlowNets for Robust Exploration。作者 Binqi Chen、Hongjun Ding、Ning Shen、Taian Guo 等（北京大学 / Zhengren Quant / Baruch / UBC）；代码 github.com/BerkinChen/AlphaSAGE。

**背景与问题**：RL-based alpha mining 存在三大痛点：

- 奖励稀疏：只有完整公式生成后才能获得反馈；
- 语义不充分：序列化 token 表示丢失公式的组合结构；
- 模式坍缩：标准 RL 最大化期望收益，天然收敛到单一最优解，与多元化因子组合的需求矛盾。

**方法**（三大创新）：

- 结构感知编码器（RGCN）：直接在公式的 AST 表示上运行的关系图卷积网络，保留组合语义；
- GFlowNets 生成框架：将 alpha 发现重构为学习生成策略 $P_\theta(\alpha)$，直接建模全空间 $\mathcal{X}$ 上高质量 alpha 的分布——奖励越高采样概率越高，天然多样化而非单点最优；
- 稠密多维奖励：终端表现 + 结构完整性 + 新颖性的内在奖励，缓解稀疏奖励的冷启动问题。

**实验与结论**：在中美股票市场真实数据上，多样性、新颖性、预测力均超基线；提出「结构 + 分布学习」的自动化 alpha 挖掘新范式。

**创新点**：首个将 GFlowNets 用于 alpha mining，专门化解「多样性 vs 高奖励」的矛盾；RGCN 编码 AST 比序列模型更适合公式结构；多维稠密奖励缓解冷启动。

**优点**：理论扎实（GFlowNets）、结构感知、多样性自然、开源。**缺点**：训练复杂度高；GFlowNets 收敛理论在金融非平稳数据下未充分验证；仅 arXiv、未经同行评审。

**后续方向**：在线学习适应非平稳市场；以 LLM 作为 GFlowNets 的策略骨干；跨频率扩展。

### AlphaQuant · ICLR 2025 Workshop

LLM 驱动的自动化鲁棒特征工程：将 AutoFE 重构为数据驱动的 MDP（原始表格数据直接作为状态输入，动作空间为特征变换操作，奖励为下游模型交叉验证性能），LLM 作为「科学家」提出假设、作为「工程师」执行图编辑，策略网络跨数据集预训练、可零样本迁移到新数据集。

### EvoAlpha · NeurIPS 2025 Workshop

LLM 作为进化算子的因子发现：突变（LLM 对现有因子局部修改）与交叉（LLM 重组多个父代的互补子表达式）替代传统盲目算子，回测结果（IC、RankIC、IR）闭环注入下一轮提示；Alpha158 种子在 CSI 300 上 15 轮进化后预测力与鲁棒性同步增强，稀疏组合优化任务上 US50 达 CW = 25.1（最佳基线 ASMCVaR 为 10.3）。

### AlphaPROBE · arXiv 2602.11917

**论文**：AlphaPROBE: Alpha Mining via Principled Retrieval and On-graph Biased Evolution。作者 Taian Guo、Haiyang Shen、Junyu Luo、Binqi Chen 等（北京大学 / Zhengren Quant / Baruch）；代码 github.com/gta0804/AlphaPROBE。

**背景与问题**：现有两大范式都缺乏全局结构视角——解耦式因子生成（DFG）中因子独立生成、关系隐性弱；迭代式因子进化（IFE）中单亲-单子链式优化、忽略全局演化网络，导致冗余搜索与多样性受限。

**方法**：将因子池建模为有向无环图（DAG），节点为因子、边为演化血缘：

- 贝叶斯因子检索器：先验项奖励高性能因子、惩罚过度优化与频繁使用；似然项评估潜在后代对现有池的新颖信息贡献；通过后验概率选择最优种子，平衡 exploration-exploitation；
- DAG 感知因子生成器：LLM 利用全部祖先血缘（而非仅直接父代）理解哪些修改策略已尝试、哪些未探索，避免冗余变异。

**实验与结论**：在 CSI 300 / 500 / 1000 上对比专家因子池、RL、SOTA LLM agents 等 8 个基线，预测精度、收益稳定性、训练效率均显著提升；消融验证贝叶斯检索机制有效；案例研究展示了完整演化路径。

**创新点**：首个用 DAG 全局拓扑建模因子演化；贝叶斯检索机制提供有原则的种子选择；完整祖先 trace 比单亲父代信息更丰富。

**优点**：全局视角、理论严谨（贝叶斯）、多市场验证、开源。**缺点**：DAG 规模增长后检索成本上升；仅 arXiv。

**后续方向**：增量式 DAG 更新；跨市场 DAG 迁移；与 RD-Agent 风格的因子-模型联合优化结合。

## 方向二：多智能体协作与人机交互

本方向的共同命题是：把量化研究员团队的角色分工显式化为智能体系统。Alpha-GPT 开创人机交互范式；SAF 用三阶段流水线组织多智能体评估；AlphaAgent 以正则化约束多智能体闭环；FactorMAD 引入对抗式辩论；R&D-Agent-Quant 在多智能体框架内调度因子与模型的联合优化；AlphaLogics 把「市场逻辑」提升为显式可优化对象；AlphaCrafter 将因子发现延伸到执行端，构成全栈闭环。因子挖掘之外，本方向还覆盖 **LLM 交易系统**这条主线——TrustTrade / BlindTrade / OOM-RL 等工作把多智能体用于交易决策本身（见「LLM Agent 与多智能体交易系统」一节）。

### Alpha-GPT · EMNLP 2025 System Demos

人机交互式 alpha 挖掘的第三种范式：Ideation（Trading Idea Polisher 将自然语言想法结构化）→ Implementation（Quant Developer 生成种子表达式并经 GP 进化）→ Review（Analyst Agent 回测并以自然语言总结）的三阶段 agentic 工作流，支持交互与自主两种模式，超大规模数据库下用分层 RAG（RAG#0～#3）自主探索；WorldQuant International Quant Championship 2024 中在超过 41000 支队伍中排名 Top-10。

### SAF（Automate Strategy Finding）· EMNLP 2025 Findings

**论文**：Automate Strategy Finding with LLM in Quant Investment。作者 Zhizhuo Kou、Holam Yu、Junyu Luo 等（HKUST / HKUST-GZ / PKU）；代码 github.com/kouzhizhuo/Automate-Strategy-Finding-with-LLM-in-Quant-investment。

**背景与问题**：传统量化策略发现存在三大局限：方法刚性、不适应动态市场；数据多样性与整合困难；模型对市场变化适应性差。

**方法**（三阶段框架）：

- Flexible Alpha Mining：LLM 从金融文献中提取、归类、过滤 alpha 因子（动量、基本面、流动性），区别于纯数据驱动的种子来源；
- Multi-agent Multimodal Market Evaluation：跨多市场状态严格回测，多角度评估因子有效性；
- Dynamic Strategy Optimization：权重门控层根据当前市场状态分配最优因子权重。

每个 alpha 形式化为：

$$\alpha_{ij}^{(t)} = w_{cs}\cdot f_{cs}(X^{(t)}_i) + w_{ts}\cdot f_{ts}(X^{(t)}_i, \ldots, X^{(t-n)}_i)$$

**实验与结论**：在 SSE50（2023.1–2024.1）实现 53.17% 累计回报；中美市场均显著优于基准；风险调整后绩效与下行保护优秀。

**创新点**：多模态、风险感知的多智能体评估；动态权重门控适应市场状态；从文献提取 seed alphas。

**优点**：完整 pipeline、多市场验证、开源。**缺点**：测试期较短；依赖文献质量；未与端到端 RL 方法直接对比。

**后续方向**：更细粒度的市场状态判定；因子类别动态扩展；多模态数据（图像、社交媒体）融合。

### AlphaAgent · KDD 2025

多智能体闭环（Idea Agent → Factor Agent → Eval Agent → Feedback）结合三类正则化对抗 alpha 衰减：AST 子树同构的原创性强制、LLM 评估的假设-因子对齐、AST 节点数与自由参数的复杂度控制；CSI 500 年均超额收益 11.0%（IR 1.5）、S&P 500 8.74%（IR 1.05），有效因子率提升 81%、token 消耗减少 30%。

### R&D-Agent-Quant · NeurIPS 2025

首个数据中心的多智能体全栈自动化框架（数据 → 因子 → 模型 → 回测 → 分析）：Research 阶段以结构化规范 $S=(B,D,F,M)$ 与「知识森林」生成假设，Development 阶段由 Co-STEER 代码生成代理实现并经 Qlib 回测验证，Analysis 单元用多臂老虎机（CLTS）调度器自适应选择「因子」或「模型」的下一轮优化方向；在 CSI 300 / 500 / 800（2008–2024）上以不到 \$10 的 API 成本实现约 2 倍于经典因子库的 ARR，使用因子数减少 70% 以上。

### FactorMAD · ICAIF 2025

多智能体辩论框架：两个具有不同因子设计视角的 LLM 智能体交替「提出候选 → 批评对方 → 改进」，收敛准则终止；代码级因子开发允许 LLM 直接生成可执行代码、不受预定义算子集约束；中国市场 5255 只股票（2014–2023，GPT-4o 基座）上 IC、RankIC、AUC 均优于 GP、DSO、AlphaGen、CoE，CSI 300 年化收益 0.063（IR 2.984）、CSI 500 年化收益 0.086（IR 3.411）。

### AlphaLogics · arXiv 2603.20247

**论文**：AlphaLogics: A Market Logic-Driven Multi-Agent System for Scalable and Interpretable Alpha Factor Generation。作者 Zhangyuhua Weng、Shengli Zhang、Taotao Wang、Yihan Xia（深圳大学）。

**背景与问题**：现有 LLM 方法只优化因子、不优化市场逻辑（market logic）——可解释的经济机制仍主要靠手工构建，难以扩展。

**方法**（三阶段闭环）：

- Market Logic Mining：从 Alpha101 / Alpha191 / Alpha158 / Alpha360 历史因子库反向提取市场逻辑（多智能体管道：FormulaStructure → FinancialSemanticsMapping → MarketLogicAbstraction），构建初始 logic 库；
- Guided Factor Generation：以市场逻辑为指导生成候选因子，回测反馈迭代优化；
- Market Logic Generation：基于初始库生成新 logic，并通过其指导因子的回测结果聚合优化每条 logic。

每条 logic 形式化为 $\langle C, B \rangle$（条件，行为）对。

**实验与结论**：CSI 500（中国）与 S&P 500（美国），测试期 2021.01–2024.12，扣除交易成本后：CSI 500 年化超额 16.72%（IR 1.5266）、S&P 500 年化超额 13.75%（IR 1.2658）；迭代市场逻辑优化随时间持续提升 logic 引导的因子质量。

**创新点**：市场逻辑作为显式可优化对象（与现有方法的核心差异）；反向提取历史 logic 库提供高质量初始化；因子-逻辑双层闭环优化。

**优点**：兼顾可解释性与可扩展性、中美双市场验证、logic 库可作研究资产。**缺点**：依赖历史因子库质量；限于 OHLCV / 价量逻辑、不涉及基本面；仅 arXiv。

**后续方向**：扩展至基本面、宏观、ESG 逻辑；logic 的因果验证；与 RD-Agent 风格的因子-模型联合优化结合。

### AlphaCrafter · arXiv 2605.05580

**论文**：AlphaCrafter: A Full-Stack Multi-Agent Framework for Cross-Sectional Quantitative Trading。作者 Yishuo Yuan、Jiayi Sheng、Sirui Zeng、Jiaqi Wang、Jiaheng Liu（南京大学）。

**背景与问题**：现有方法或遵循「冻结设计哲学」（固定特征集、固定架构、手动调参），或采用拟人化角色扮演多智能体（引入模拟行为偏差与高推理延迟），或终止于因子生成阶段（如 RD-Agent、AlphaAgent），缺乏将因子发现、制度自适应选择与风险约束执行持续耦合的全自动框架。

**方法**：Miner、Screener、Trader 三个专业化智能体围绕共享记忆协同：

- Miner（因子矿工）：LLM 引导搜索持续扩展因子库——生成候选、验证（IC、ICIR、换手率、衰减曲线）、条件接受、记忆更新、自主终止、定期剪枝衰减因子；
- Screener（筛选器）：评估当前市场制度，对每个因子计算制度适宜性得分，多样化选择后分配权重与方向，形成制度条件化因子组合；
- Trader（交易员）：将因子组合转化为显式风险约束的量化策略——参考策略按复合得分 $\phi_{i,t} = \sum_{j=1}^{|E_t|} w_j \cdot d_j \cdot f_j(x_{i,t})$ 排序选取多头与空头，总暴露 $\beta = 0.8$，净暴露偏置 CSI 300 取 $\gamma = 1$（纯多头）、S&P 500 取 $\gamma = 0.5$，回测优化超参后执行。

**实验与结论**：CSI 300 回测夏普 1.5322（AR 18.27%），实盘夏普 0.7002（AR 5.70%，MDD -5.31%）；S&P 500 回测夏普 1.2025（AR 12.79%），实盘夏普 0.7212（AR 9.26%，MDD -3.95%）。在从回测过渡到实盘时，所有基线（含 LSTM、Transformer、TradingAgents、AlphaAgent、RD-Agent）均显著衰减甚至崩溃，AlphaCrafter 是唯一在所有阶段与市场保持正风险调整后收益的方法；10 次独立试验的**跨试验方差最低**——这是 Multi-Agent 框架「稳定性」的首个量化证据；动态库维护使 IC 稳定在 0.015–0.025 区间。消融显示：去 Screener 回撤恶化最多（CSI 300 MDD 由 -8.40% 恶化至 -12.01%），去 Trader 夏普最低。

**在多智能体谱系中的位置**：可视为对 TrustTrade（共识机制）与 FactorEngine/Hubble（程序级因子挖掘）的集成与超越——把因子发现、制度自适应筛选与风险约束执行持续耦合为全栈闭环。

**局限**：依赖 LLM API 成本与推理延迟（仅适合日度调仓）；未报告完整交易成本（佣金+滑点+市场冲击）细节；未在其他资产类别与更长周期验证；GPT 5.3 Codex 生成因子的结构新颖性最高但实盘表现不及 Claude Opus 4.6，说明因子新颖性与投资结果并非单调关系。

### LLM Agent 与多智能体交易系统的技术演进

因子挖掘之外，方向二的另一条主线是把 LLM 组织为**交易决策系统**。从单 Agent 到全栈 Multi-Agent 的五个阶段：

```text
Stage 1（2024Q1-Q2）：单 Agent 决策
  单一 LLM 接收市场数据并输出交易信号
  局限：无记忆、无协作、幻觉率高
    ↓
Stage 2（2024Q3-Q4）：角色扮演多 Agent
  引入 Analyst / Trader / Risk Manager 等角色
  代表：Expert Investment Teams（2026-02）
  局限：角色边界模糊，信息传递噪声大
    ↓
Stage 3（2025Q1-Q2）：细粒度任务分解
  交易流程拆分为可独立优化的子任务
  代表：AlphaCrafter 的 Miner-Screener-Trader 三元组
    ↓
Stage 4（2025Q3-Q4）：共识机制与信任校准
  跨 Agent 一致性检验，解决「统一信任」偏差
  代表：TrustTrade、BlindTrade
    ↓
Stage 5（2026）：闭环自适应系统
  全栈集成 + 持续学习 + 在线优化
  前沿：OOM-RL 提出用真实资金损失作为对齐信号
```

### TrustTrade · arXiv 2603.22567

**论文**：TrustTrade: Human-Inspired Selective Consensus Reduces Decision Uncertainty in LLM Trading Agents。作者 Minghan Li 等。

**核心问题**：识别并量化了 LLM 交易 Agent 中的**统一信任（uniform trust）偏差**——Agent 隐式假设所有检索到的信息都是事实性的，噪声环境下导致极端的风险-回报行为。

**方法**：多 Agent 选择性共识框架——多个独立 LLM Agent 聚合信息，基于**语义和数值一致性动态加权**信号；引入**确定性时间信号**作为可复现锚点；**反射记忆机制**跨会话调整风险偏好。

**实验与结论**：在高噪声市场环境中，将 LLM 交易行为从极端风险-回报区间校准至**人类对齐的中风险-中回报区间**。

**优点**：首次系统识别统一信任偏差并给出三层解决机制（交叉 Agent 一致性、时间锚定、反射记忆）。**缺点**：共识阈值人工设定；多 Agent 聚合的 token 开销大。

### BlindTrade · arXiv 2603.17692

**论文**：Can Blindfolded LLMs Still Trade? An Anonymization-First Framework for Portfolio Optimization。作者 Joohyoung Jeon、Hongchul Lee。

**核心问题**：LLM 交易 Agent 的收益来自**真正的市场理解，还是对训练数据中股票-收益关联的记忆**？（与 Hubble 指出的 LLM 时间泄漏问题同源，但从交易端切入。）

**方法**：**匿名化优先**——隐去所有股票标识后再让 LLM 推理；四个 Agent 输出评分，配合 GNN 聚合与 PPO-DSR 策略执行；**负控制实验**（打乱标识映射）验证信号合法性。

**实验与结论**：2025 年 YTD Sharpe 1.40 ± 0.22（20 个种子）；在波动环境中表现优异，但**趋势性牛市中 Alpha 下降**。

**优点**：用匿名化+负控制首次把「记忆偏差」变成可检验的实验设计。**缺点**：牛市环境 Alpha 衰减；匿名化可能丢弃基本面先验信息。

### Expert Investment Teams · 2026-02

**论文**：Expert Investment Teams（Kunihiro Miyazaki 等）。

角色扮演多智能体的代表：Analyst / Trader / Risk Manager 等层级化角色分工与报告机制，每个角色持有独立记忆。**局限**：角色边界模糊、角色间通信开销大——正是后来细粒度任务分解（AlphaCrafter）与共识机制（TrustTrade）要解决的问题。

### HiveMind

贡献引导的多智能体框架：**在线提示记忆**——各 Agent 的历史贡献反馈到提示层做在线优化。**局限**：金融场景验证不充分，更多是通用多智能体机制 proof-of-concept。

### OOM-RL

面向 Stage 5（闭环自适应）的前沿工作：以**真实资金损失作为对齐信号**训练多智能体交易系统，并施加**代码覆盖约束**限制策略更新范围。这是把「部署即采样」式在线优化引入量化交易的尝试。**局限**：20 个月回测仅覆盖特定市场，泛化性存疑；真实资金损失对齐的样本效率与安全性仍待检验。

### 交易多智能体的开放问题

1. **协调优先假设（CPH）**（Nguyen & Pham，2026，见方向五）：协调协议设计对系统性能的影响大于模型规模——尚缺严格实证验证；
2. **回声室效应**：当多个 Agent 共享相同底层 LLM 时，它们的「独立性」是否只是表面现象？
3. **最优 Agent 数量**：增加 Agent 数量是收益递减还是收益崩溃？
4. **共性局限**：多数工作未报告完整交易成本的净收益；回测窗口普遍较短（1-3 年），缺乏跨制度转换的长期验证；Agent 间通信的 token 开销在实际部署中可能成为成本瓶颈；缺乏对对抗攻击的鲁棒性测试。

## 方向三：RL 与工具增强的端到端训练

本方向的共同命题是：不再依赖提示工程的多轮迭代，而是用强化学习（PPO、GRPO）端到端训练专门的策略模型。AlphaQuanter 在工具增强的决策工作流上训练交易智能体；Alpha-R1 训练语义门控的因子筛选模型；AlphaAgentEvo 把「进化本身」作为多轮智能体强化学习（ARL）的训练目标，是连接本方向与方向四的桥梁。本方向同时覆盖传统 DRL 在金融组合优化与交易中的理论深化（SNAPO、MetaRL-GBWM、MACE 等，见「RL 在组合优化与交易中的延伸」一节）。

### AlphaQuanter · ACL Findings 2026

工具增强 MDP $\langle S, A, T, R \rangle$ 上的端到端 RL 交易智能体：动作分为查询动作 $A_q$（市场 / 基本面 / 情绪 / 宏观工具）与决策动作 $A_d$（BUY / SELL / HOLD），奖励 $R = \alpha R_{\text{result}} + R_{\text{format}} + R_{\text{tool}}$ 同时塑造结果与过程；Plan → Acquire → Reason → Act 的认知工作流使每步决策可审计。基于 verl 的改进 PPO 训练 3B / 7B 模型，AlphaQuanter-7B 在 GOOGL、MSFT、META、NVDA、TSLA 五只标的上 ARR 绝对提升 18.45%，并实证小模型上单智能体 + RL 优于多智能体辩论（GPT-4o 除外）。

### Alpha-R1 · arXiv 2512.23515

**论文**：Alpha-R1: Alpha Screening with LLM Reasoning via Reinforcement Learning。作者 Zuoyou Jiang、Li Zhao、Rui Sun 等（上海交通大学 / StepFun / FinStep）；代码 github.com/FinStep-AI/Alpha-R1。

**背景与问题**：因子投资面临两大结构性挑战：

- 信号衰减与非平稳性：传统时序模型依赖历史相关性，在宏观环境变化时泛化能力差；
- 语义 rationale 被忽视：现有方法将 alpha 压缩为数值时间序列，丢弃了决定其在特定市场条件下经济相关性的语义逻辑。

**方法**（三阶段管线）：

- 数据抽象与记忆构建：将技术指标、新闻等异构数据转化为文本原子单元，通过 LLM 迭代构建全球市场记忆 $M_{\text{global}}$；
- 语义画像构建：由 LLM 生成因子语义描述 $\alpha_{\text{des},i}$（机制、适用市况、失效条件）与当前市场状态 $S_t$；
- 推理与优化：Alpha-R1（8B，基于 Qwen3-8B）在语义决策上下文 $C_t = \{\alpha_{\text{des},i}\} \oplus S_t$ 上推理，输出选中因子列表 $\mathcal{A}_t$——一种上下文条件化的稀疏门控，LLM 根据因子画像与市场状态的语义对齐度选择性激活或停用因子。

**RL 训练**（GRPO，无评论家网络）：奖励由三部分组成——规则化绩效奖励（基于固定系数线性因子模型的超额收益）、质量调整奖励（外部 LLM-as-Judge 评估推理质量与连贯性，对正收益折扣、对负收益放大惩罚）、结构化惩罚（鼓励稀疏因子选择，惩罚无效或不可解析输出）。

**实验与结论**：测试期 2025.01–2025.06，资产池为 CSI 300 与 CSI 1000；在两个池上均持续优于 A2C、PPO、Lasso、XGBoost、LightGBM 及通用推理 LLM；在 CSI 1000（域外）上展现卓越的零样本迁移能力，而传统 RL 模型明显过拟合；消融实验表明去除 RL 优化后模型夏普比率跌至 -0.77，证明通用推理能力不足以产生正 alpha，RL 对齐至关重要。

**创新点**：

- 语义门控机制：将因子筛选从「数值回归」升级为「语义推理」，使模型能理解「价值因子在通胀期有效、在衰退期失效」这类宏观逻辑；
- GRPO 金融适配：将 DeepSeek-R1 的 critic-free RL 范式迁移至金融因子筛选，用客观市场收益替代主观人类偏好作为奖励信号；
- 固定线性打分 + 动态因子激活：线性模型提供稳定低方差的收益映射，LLM 负责非平稳性适应，降低纯动态模型的估计噪声。

**优点**：首次将 LLM 推理与 RL 训练系统性结合用于 alpha 筛选；8B 小模型经专业化训练即超越通用大模型，验证「领域专精 > 模型规模」；决策过程天然可解释（因子画像 + 市场状态 + 选中理由）。**缺点**：测试期仅半年；依赖 LLM 生成语义描述存在幻觉风险；固定线性打分器假设因子收益线性可加，可能忽略非线性交互。

**后续方向**：扩展至全球多市场验证；以梯度提升等非线性组合模型替代线性打分器并保持可解释性；探索因子级风险预算与尾部风险约束。

### AlphaAgentEvo · ICLR 2026

自进化智能体强化学习（Agentic Reinforcement Learning, ARL）框架：将 alpha mining 从脆弱的「搜索-回测-重启」循环转向连续进化轨迹——策略 LLM 条件于完整历史轨迹进行反思，每轮生成多个并行候选并调用回测工具评估，分层奖励（工具调用有效性 → 种子一致性与探索多样性 → 性能改进与连续进步）引导能力递进；将 GRPO 扩展为多轮 ARL，仅 4B 参数即超越配置最先进闭源推理模型的 LLM 驱动进化方法。

### RL 在组合优化与交易中的延伸

除端到端训练 LLM 交易智能体外，传统 DRL 在金融决策上也在经历一次理论深化。四代演进：

```text
Gen 1（2019-2021）：标准 DRL
  DQN / PPO / A2C 直接应用于固定环境
  局限：环境过简化；交易成本忽略
    ↓
Gen 2（2022-2023）：环境工程化
  引入更真实的市场冲击模型、滑点模型
  局限：每环境需独立训练；跨环境泛化差
    ↓
Gen 3（2024-2025）：Meta-RL 与多任务学习
  预训练 + 快速适应
  突破：MetaRL-GBWM 实现 97.8% 最优效用近似
    ↓
Gen 4（2025-2026）：理论深化
  伴随方法（SNAPO）、递归效用、熵正则化 HJB 方程
  突破：从「能用」到「有理论保证」
```

#### SNAPO · arXiv 2605.06570

**论文**：SNAPO: Smooth Neural Adjoint Policy Optimization for Optimal Control via Differentiable Simulation。作者 Dmitri Goloubentsev、Natalija Karpichina。

**范式转变**：从**黑盒策略梯度**到**白盒伴随微分**。将神经网络策略嵌入已知可微分模拟器，用光滑近似替代硬约束，通过单次伴随反向传播计算所有参数和输入的精确梯度——传统 RL 通过采样估计策略梯度，SNAPO 利用可微分模拟器的结构信息实现 **O(1) 复杂度**的敏感度计算。

**局限**：需要环境模拟器可微分——对于高度离散化的市场环境（如限价订单簿），可微分近似可能引入显著误差。

#### MetaRL-GBWM · arXiv 2605.02300

**论文**：A Meta Reinforcement Learning Approach to Goals-Based Wealth Management。作者 Sanjiv R. Das 等。

**核心贡献**：证明**预训练-微调范式可以扩展到金融决策领域**。传统上每个投资者的投资组合优化问题都需独立求解；MetaRL 在数千个 GBWM（Goals-Based Wealth Management）问题上预训练，学会提取问题的「元结构」。

**关键结果**：达到最优 DP 期望效用的 **97.8%**；对资本市场制度变化高度鲁棒；推理阶段 **~0.01 秒**生成近最优策略。

**局限**：仅仿真环境验证；预训练问题分布与真实市场问题的「分布差距」可能导致预训练知识在实盘失效。

#### MACE：真实市场冲击建模 · arXiv 2603.29086

**论文**：Realistic Market Impact Modeling for Reinforcement Learning Trading Environments。作者 Lucas Riera Abbade、Anna Helena Reali Costa。

**核心价值**：量化了**忽略市场冲击这一简化假设对 RL 研究结论的扭曲程度**——在固定 10bps 基线下表现最好的算法，在 Almgren-Chriss 冲击模型下可能变成最差。

**关键发现**：DDPG 的 OOS Sharpe 从 -2.1 跃升至 0.3（保证金交易）；SAC 则从 -0.5 降至 -1.2——**算法-成本模型交互强烈依赖环境**。对 RL 交易研究的警示：不报告成本模型设定的 Sharpe 结论不可比。

## 方向四：自进化与经验记忆

本方向的共同命题是：跨迭代、跨会话的知识积累。CogAlpha 以七层认知智能体提供分层经济视角并以代码进化闭环；QuantaAlpha 将每次挖掘运行建模为可进化的轨迹，用轨迹级变异与交叉实现结构化探索；FactorMiner 以模块化技能与结构化经验记忆解决「知识遗忘」。三者的差异在于积累什么：认知层次、决策轨迹，还是符号化的成功 / 失败模式。

### CogAlpha · arXiv 2511.18850

**论文**：Cognitive Alpha Mining via LLM-Driven Code-Based Evolution。作者 Fengyuan Liu、Yi Huang、Sichun Luo 等（HKU / 中国移动九天研究院 / Grace Investment Machine）。

**背景与问题**：现有 LLM-based 方法仍只在浅层因子空间搜索：神经模型不透明，符号方法冗余且缺乏经济根基；共同局限是无法进行兼具逻辑一致性与创造性跳跃的人类式探索。

**方法**：

- 七层智能体层次（基于 OHLCV）：L I 市场结构与周期（AgentMarketCycle、AgentVolatilityRegime）；L II 极端风险与脆弱性（AgentTailRisk、AgentCrashPredictor）；L III 价量动态（AgentLiquidity、AgentOrderImbalance、AgentPriceVolumeCoherence、AgentVolumeStructure）；L IV 价格-波动率行为（AgentDailyTrend、AgentReversal、AgentRangeVol、AgentLagResponse、AgentVolAsymmetry）；L V 多尺度复杂性（AgentDrawdown、AgentFractal）；L VI–VII 更微观的行为 / 微结构层，共 21 个 unique agents；
- 五种 paraphrasing 风格（一致 / 创造 / 发散 / 具体）扩展语义覆盖；
- 多智能体质量检查器：Judge、Logic Improvement、Code Quality、Code Repair 四种 agent 验证、改进、修复代码，通过则入池；
- 进化搜索：基于成功 / 失败的 top alphas 引导下一代生成，形成闭环学习。

**实验与结论**：5 个数据集（3 个股票市场），CSI 300 为主；大量单因子实现 IC > 0.05、RankIC > 0.07；预测准确率、稳健性、泛化均优于基线。

**创新点**：「Cognitive Alpha Mining」概念——从蛮力搜索 / 浅层生成走向知识驱动、认知启发；七层智能体层次提供分层经济视角；多智能体质检 + paraphrasing 兼顾质量与多样性。

**优点**：分层视角全面、代码级灵活、可解释（每个 alpha 附详细注释）。**缺点**：21 个 agent 工程复杂、运行成本高；OHLCV 输入受限，未扩展基本面与另类数据。

**后续方向**：扩展至基本面、宏观、文本输入；自适应 paraphrasing 策略选择；与 RD-Agent 风格的因子-模型联合优化结合。

### QuantaAlpha · arXiv 2602.07085

**论文**：QuantaAlpha: An Evolutionary Framework for LLM-Driven Alpha Mining。作者 Jun Han、Shuo Zhang、Wei Li、Zhi Yang 等（SUFE / QuantaAlpha / Stanford / PKU / SYSU / SEU）；代码 github.com/QuantaAlpha/QuantaAlpha。本节数字以 [QuantaAlpha_报告.md](QuantaAlpha-%20An%20Evolutionary%20Framework%20for%20LLM-Driven%20Alpha%20Mining%20%E2%80%94%20%E4%B8%AD%E6%96%87%E6%B7%B1%E5%BA%A6%E5%88%86%E6%9E%90%E6%8A%A5%E5%91%8A.md) 为准。

**背景与问题**：现有 agentic 系统在真实市场的非平稳与低信噪比环境下面临三大局限：

- 脆弱可控性：迭代精炼由噪声回测反馈驱动，引发语义漂移，更新逐渐偏离最初的经济学机制；
- 可信度有限：随机重生成不显式继承已验证 rationale，缺乏可追溯的谱系，因子难以审计；
- 探索受限：过度利用种子局部邻域，多样性差、因子拥挤。

**方法**：将每次端到端挖掘运行建模为一条轨迹 $\tau = (s_0, a_0, s_1, a_1, \ldots, s_n)$，四个核心组件：

- 多元化规划初始化：生成 10 个互补的研究方向（变化信号来源、时间尺度与机制类型；种子取自 Alpha158(20) 低相关分组），形成初始轨迹池；
- 可控因子构造：基于标准化算子库 $\mathcal{O}$ 与 AST 中间表示，按 hypothesis → 语义描述 → AST → 可执行代码的链条生成因子，编译失败触发保语义的修复；
- 轨迹级自进化（核心）：Mutation 通过自反思诊断对低终端奖励负最大责任的次优步骤，冻结轨迹前缀、仅重写该局部片段及其后续，实现靶向修复；Crossover 从高奖励父轨迹中识别持续贡献于高累积奖励的片段（假设模板、因子构造模式、修复动作）并重组为连贯子轨迹；
- 最终因子池：约 150 个验证因子，准入要求与池内所有因子绝对相关性低于 0.7，池大小上限为已挖掘因子总数的 50%，提交下游 LightGBM（TopkDropout，扣除交易成本）评估。

**生成门控**：语义一致性验证（LLM 验证器检查 hypothesis、语义描述、符号表达式与代码之间的对齐）+ 复杂度控制（符号长度、自由参数、特征集合的加权度量，权重系数未公开）+ 冗余控制（AST 最大公共子树度量结构相似度，并在验证面板上做输出级相关性过滤）。

**实验与结论**：训练 2016–2020、验证 2021、测试 2022-01 至 2025-12；Qlib 回测，买入 0.05% / 卖出 0.15% 交易成本，成交价为次日开盘价：

- 主结果（GPT-5.2）：IC = 0.0472（所有方法中最高）、ICIR 0.2691、Rank IC 0.0459、ARR = 4.68%、MDD = 11.8%；
- 相比 RD-Agent（GPT-5.2）：IC 提升 0.0186、ARR 提升 1.10%、MDD 降低 4.96%；相比 AlphaAgent（GPT-5.2）：IC 提升 0.0125、ARR 提升 3.57%、MDD 降低 2.09%；
- 跨市场零样本迁移：CSI 300 挖掘的因子迁移至 CSI 500 与 S&P 500，四年累计超额收益分别约 40.28% 与 19.1%；
- 消融（DeepSeek-V3.2）：去变异 IC 降幅最大（-0.0079），去交叉 -0.0060，去规划 ARR -0.72%；去复杂度控制 ARR -0.95%、MDD 增加 2.31%；
- 成本：每次主运行约 20 小时、约 180 万 tokens。

**创新点**：轨迹级（而非单点）变异与交叉，实现结构化探索与精炼；显式继承已验证决策，形成可追溯谱系；AST 中间表示确保 hypothesis 与代码语义一致；自反思的失败步骤定位实现精准修正。

**优点**：自进化轨迹机制创新；在 2023 年 A 股制度转换等非平稳场景中保持稳健；多市场零样本迁移强。**缺点**：依赖最新最强 LLM；轨迹存储与变异工程复杂；复杂度权重系数等超参未公开；真实部署仍需额外的交易成本建模、风险控制与实盘验证；仅 arXiv。

**后续方向**：多目标轨迹优化（收益 / 风险 / 换手率）；跨频率扩展；与 RD-Agent 类因子-模型联合优化结合；最优迭代次数的自动确定（收敛性研究显示约 15 轮后性能开始衰减）。

### FactorMiner · arXiv 2602.14670

**论文**：FactorMiner: A Self-Evolving Agent with Skills and Experience Memory for Financial Alpha Discovery。

**背景与问题**：公式化因子挖掘面临三大挑战——搜索空间巨大（组合空间随算子与参数指数级增长）；知识积累匮乏（传统 GP / RL 无法在多次探索会话间保留和复用洞见）；可解释性约束（金融合规与风险管理要求透明可审计公式）。随着因子库扩大，「相关性红海」使新因子须同时满足质量与低冗余，而现有方法孤立优化单个因子、忽视与已有库的全局交互。

**方法**：围绕模块化技能架构与结构化经验记忆两大机制，以 Ralph Loop 范式自进化迭代：

- 模块化技能架构：算子层含 60+ 金融算子（算术、时序统计、截面、平滑、回归、逻辑），GPU 加速；验证流水线为快速 IC 筛选 → 相关性检查 → 批次去重 → 完整验证；准入要求 $|\mathrm{IC}| \geq 0.04$ 且与现有库最大相关性低于 0.5，若新因子 IC ≥ 0.10 且 ≥ 1.3 倍被替换因子则触发替换；
- 经验记忆系统 $\mathcal{M}$：形成算子 $F$ 从挖掘轨迹蒸馏成功模式 $P_{\text{succ}}$ 与禁区 $P_{\text{fail}}$；演化算子 $E$ 整合新记忆、合并冗余、丢弃低效用条目；检索算子 $R$ 在生成阶段检索上下文相关记忆，作为 LLM 策略的提示级约束；
- Ralph Loop：Retrieve → Generate → Evaluate → Distill → Loop。

**实验与结论**：数据为 CSI500 / CSI1000 / HS300（10 分钟频）与加密货币市场；LLM 主干 Gemini 3.0 Flash；样本外协议为 2024 年选因子并冻结、2025 年及跨市场测试：

- 因子质量：CSI500 IC 8.25%（ICIR 0.77）、CSI1000 7.78%（0.76）、HS300 7.46%（0.38）、Crypto 3.82%（0.28），四个市场均最优；对比适配版 Alpha101（4.49%）、AlphaAgent（4.48%）、GPLearn（5.06%），IC 约为次优方法的 1.5–2 倍；
- 下游任务：CSI500 上 IC 加权组合 ICIR 1.31、XGBoost 因子选择 ICIR 1.29，均显著高于基线；Crypto 等权组合 IC 9.48%、ICIR 0.62，显示因子捕捉了跨资产不变的价格-成交量动态；
- 记忆消融：有记忆变体生成 96 个高质量候选（yield 60.0%），无记忆基线仅 32 个（20.0%），产量提升 3 倍；同时有记忆变体主动拒绝更高比例的相关因子（55.2% vs 43.8%），确认演化算子作为战略过滤器的功能；
- 计算效率：算子级 GPU 较 Pandas 加速 8–59 倍（TsRank 从 1843 ms 降至 31 ms），因子级端到端加速 23–27 倍；评估 1000 个候选因子约需 6 分钟（Pandas 约 70 分钟）；
- 发布 110 个 A 股高频因子的开放公式化因子库，平均两两相关性 0.203。

**创新点**：经验记忆系统解决「知识遗忘」，通过符号化的成功 / 失败模式实现跨会话结构知识复用；全局库视角（候选如何补充现有库）；GPU + 多进程 + C 编译的多层工程优化实现大规模可行性。

**缺点**：未纳入交易成本；缺少与端到端深度模型的直接对比；记忆蒸馏依赖 LLM 质量，偏差可能被持续放大；替换机制可能过于激进。

**后续方向**：交易成本感知挖掘；在线记忆更新以适应 regime switching；扩展至期权、期货、外汇与 tick 级；记忆可视化审计工具；对抗性鲁棒性测试。

## 方向五：安全执行与基准评测

本方向的共同命题是：把 LLM 因子挖掘从「能跑通」升级为「可审计、可复现、可比较」。Hubble 以 DSL / AST 沙盒与双通道 RAG 解决安全执行与多样性控制；From Hypotheses to Factors 用约束 DSL、固定门限与仅追加轨迹把智能体嵌入可复现的实证协议（并在加密货币市场验证）；AlphaBench 则补上横向比较的一环，首次系统评测 LLM 的因子生成、评估与搜索能力。评测可靠性研究进一步延伸到策略代码生成（QuantCode-Bench）、实时预测（PolyBench）与多智能体系统（Nguyen & Pham 的 CPH/CBS），见「面向交易与多智能体的评测基准」一节。

### Hubble · arXiv 2604.09601

**论文**：Hubble: An LLM-Driven Agentic Framework for Safe, Diverse, and Reproducible Alpha Factor Discovery。

**背景与问题**：naive 地将 LLM 用于公式挖掘会同时引入多种故障模式：不安全代码执行；语义无效表达式；拥挤模板的重复发现；收敛于低新颖性的狭窄信号集。现有工作多关注生成质量，对执行安全、可复现性、因子家族多样性与拥挤控制的联合要求关注不足。

**方法**（五大核心模块）：

- DSL + AST 沙盒：候选公式以受限 DSL 编写（输入为 OPEN、HIGH、LOW、CLOSE、VOLUME、VWAP 日度面板），解析为 AST 后经三层验证——白名单节点（exec-free）、复杂度限制、语义有效性，彻底消除代码注入与运行时崩溃；
- 双通道 RAG：正通道检索代表性公式或蒸馏模板以鼓励探索，负通道检索拥挤模板作为「应避免」参考，把检索语料从被动示例来源变为探索的控制信号；
- 评估流水线：RankIC、Pearson IC、年化 ICIR、覆盖率、分桶 / 多空收益、换手率、AST 复杂度，并以 Bartlett 核 HAC 方差估计（Newey-West 型自动滞后选择）做显著性检验；
- 标准化评分 + 家族感知选择：先对各指标做 tanh 标准化得到基础分，再叠加惩罚与奖励：

$$\text{score}(\alpha) = \text{score}_{\text{base}}(\alpha) - \lambda_c P_{\text{crowded}}(\alpha) - \lambda_s P_{\text{similar}}(\alpha) - \lambda_f P_{\text{family}}(\alpha) + \lambda_n B_{\text{novelty}}(\alpha)$$

其中 $P_{\text{crowded}}$ 惩罚接近负 RAG 拥挤模板的因子，$P_{\text{similar}}$ 惩罚近重复候选，$P_{\text{family}}$ 惩罚单一家族内过度集中，$B_{\text{novelty}}$ 奖励扩展新家族的候选，使多样性约束从候选池传递到最终选择；

- 反馈与持久化：每轮记录顶尖公式、错误摘要、过 / 欠探索家族与提示元数据，存储为结构化目录（追加式记录、JSON 摘要、提示 / 响应快照），使挖掘过程可审计、可复现。

**实验与结论**：数据为 S&P 500 成分股（501 只有效股票），发现期 2022-01 至 2025-05（840 个交易日），样本外 2025-06 至 2026-03（195 个交易日，完全未参与发现）；3 轮挖掘、每轮批次 20、Top-k = 5：

- 三轮共处理 60 个主候选与 44 个反馈候选，完成 104 次完整评估，零运行时崩溃、零解析崩溃、零存储失败；最佳分数出现在第二轮（5.622）而非首轮（5.195），首轮拓宽探索、后续轮次精炼主题；
- 样本内 Top-5 因子集中于区间、波动率、价格趋势三个家族，而非拥挤的流动性-成交量模体；
- 样本外：Range-1 与 Range-2 显著增强（Pearson IC 的 HAC t 分别为 2.98 与 3.01，多空 t 为 2.17 与 2.31），Volatility-1 保持强劲（RankIC HAC t = 2.25，多空 HAC t = 2.60），Volatility-2 证据稍弱，Trend-1 明显衰减（Pearson IC 反号至 -0.0034、多空不再显著）——样本内排名最低的因子也是样本外衰减最明显的，说明系统排名并非任意；
- 跨后端鲁棒性：以 Hunter-Alpha 替换 Nemotron-120B 后峰值分数略低（5.460 vs 5.622），但定性恢复相似因子画像（仍来自区间、波动率与趋势家族），表明系统设计不依赖单一后端。

**创新点**：双通道 RAG 从被动检索变为主动控制信号；AST 沙盒确保零崩溃；家族感知评分有效控制多样性；HAC 显著性检验符合金融时序严谨性要求。

**缺点**：因子未做市场 / 行业 / 风格中性化，IC 可能混入系统性风险暴露；OOS 为单分割且偏短（约 9 个月）；RAG 语料库可能残留早期主题偏差；LLM 时间泄漏——预训练语料可能包含发现期之后的金融文献，模型或已内化「哪些因子家族有效」的元知识；LLM 叙事偏差——每个因子都附带现成的金融原理故事，解释的合理性会降低研究者的批判阈值；无交易成本评估（Top 因子换手率 11–37%）。

**后续方向**：中性化因子评估（市场 / 行业 / 规模 / 价值 / 动量）；滚动前向 + 多市场验证；交易成本感知挖掘 + 组合优化；严格消融实验；时间防火墙微调 LLM。

### From Hypotheses to Factors · arXiv 2604.26747（加密货币）

**论文**：From Hypotheses to Factors: Constrained LLM Agents in Cryptocurrency Markets。作者 Yikuan Huang、Zheqi Fan、Kaiqi Hu、Yifan Ye（HKUST / 罗格斯大学 / BNBU）。

**背景与问题**：LLM 智能体是有前景的实证发现工具，但其灵活性可能把发现过程变成「不受控搜索」——智能体可通过自由修改特征、代码、数据划分或评估规则来「作弊」，使优异的样本内表现只反映数据挖掘而非真实可预测性。

**方法**：将因子发现建模为智能体化的序列化假设搜索（sequential hypothesis search），以符号化假设为动作、以确定性实证检验为反馈：

- 推理智能体（GPT-5.4，固定系统提示）读取仅追加（append-only）的实验轨迹，识别已确认、已拒绝与接近门限的机制，每轮生成机械候选（已有成功配方的局部变体，负责局部精细搜索）与假设候选（LLM 推理提出，负责全局探索）的混合批次；
- 候选被翻译为约束 DSL 的可执行配方：仅允许预批准的逐点（point-in-time）列，必须包含至少一个时序或非线性变换，配方足够浅层以便人工检查，防止任意代码生成与前视偏差；
- 确定性评估引擎执行固定数据划分、固定选择门限（平均 IC 与 IC t 统计量）、5 bp 单向交易成本与投资组合检验；推理与评估分离——智能体控制搜索方向但无法修改评估规则；
- 池治理：通过门限的候选进入持有池，再按实证强度、机制多样性与冗余度筛选为优质池；搜索停止后以岭回归组合优质因子并做样本外测试。

**实验与结论**：数据为 CoinMarketCap 加密货币日度面板（2020-01 至 2025-12），训练窗口 2020–2022、验证 2023、纯样本外 2024–2026：

- 顶级单因子集中于小市值、低波动、高日内波幅特征；最优单因子 h1_smallcap_lowvol_logret_vol 纯样本外夏普达 +2.412；
- 等权多空组合在扣除 5 bp 单向成本后实现年化收益 44.5%（摘要口径 44.55%）、波动率 28.7%、夏普 1.551、最大回撤 -23.6%；五分位组合呈单调关系；
- 成本敏感性：即便 30 bp 单向成本下仍保持 1.2% 年化收益与 0.46 夏普；市值加权组合表现较差，alpha 主要集中于小市值资产。

**创新点**：首个把因子发现形式化为「符号假设为动作、确定性检验为反馈」的智能体序列搜索；约束 DSL、固定门限与仅追加轨迹构成可审计工作流，将自然语言假设链接到可执行信号定义；提供加密货币市场实证，并通过交易成本与容量分析暴露方法局限。

**局限**：搜索效率受 DSL 约束限制；依赖 LLM 推理质量；计算开销高于单轮训练。

### AlphaBench · ICLR 2026

首个系统评测 LLM 公式化 alpha 因子挖掘（FAFM）能力的基准，覆盖三个核心任务：因子生成（Text2Alpha、Directional Mining）、因子评估（Ranking、Scoring、Signal Classification、Pairwise Selection）、因子搜索（CoE 链式精炼、ToT 带剪枝分支探索、EA 种群进化），并以 Reliability、Stability、Accuracy 等指标考察模型类型、提示范式与推理策略的影响；实验揭示 LLM 在自动化因子挖掘上潜力强大，但在鲁棒性、搜索效率与实用性上仍有持续挑战。

### 面向交易与多智能体的评测基准

因子挖掘评测之外，评估可靠性研究还覆盖策略代码生成、实时预测与多智能体系统三个层面。

#### PolyBench · arXiv 2604.14199

**论文**：PolyBench: Benchmarking LLM Forecasting and Trading on Live Prediction Market Data。作者 Pu Cheng、Juncheng Liu、Yunshen Long 等。

**核心价值**：**防污染设计**——使用实时市场数据（2026 年 2 月 6-12 日），LLM 无法事先「看到」这些事件，从根本上消除训练数据泄漏。

**关键发现**：**表面语言流畅性与真实概率推理能力之间的鸿沟**——7 个 LLM 均表现出高置信度，但仅 2 个能转化为正收益（MiMo-V2-Flash: 17.6% CWR；Gemini-3-Flash: 6.2% CWR）。

#### QuantCode-Bench · arXiv 2604.15151

**论文**：QuantCode-Bench: Evaluating LLMs for Algorithmic Trading Strategy Generation。作者 Alexey Khoroshilov 等。

**多阶段评估管道**：语法正确性 → 回测执行 → 交易存在性 → 语义对齐（LLM judge）。

**关键发现**：LLM 生成交易策略的主要限制不是语法而是**交易逻辑操作化**、API 使用和语义一致性；**agentic 多轮设置显著优于单轮**——与 AlphaAgentEvo 等把多轮交互作为训练目标的动机互为印证。

#### Multi-Agent 评估框架（CPH/CBS）· arXiv 2603.27539

**论文**：Toward Reliable Evaluation of LLM-Based Financial Multi-Agent Systems。作者 Phat Nguyen、Thang Pham。

**方法**：四维度分类体系（架构、协调、记忆、工具），系统评估金融多智能体系统；提出**协调优先假设（CPH）**——协调协议设计对系统性能的影响大于模型规模；以及 **CBS（协调盈亏平衡价差）**指标——使协调开销与性能收益相抵的最小价差，为「多 Agent 是否值得」提供了可量化的判据。

**意义**：为方向二中「最优 Agent 数量」「回声室效应」等开放问题提供了第一个统一评估框架。

### 五大普遍性评估失败

评估研究的共同底线——无论因子挖掘、策略生成还是多智能体交易，回测有效性都受以下偏差威胁：

| 偏差类型 | 描述 | 影响程度 | 检测难度 |
| :--- | :--- | :--- | :--- |
| 前瞻性偏差 | 策略使用未来不可得的信息 | 极高（可反转结论） | 高 |
| 幸存者偏差 | 仅使用当前存在的股票回测 | 高（高估 5-15%） | 中 |
| 回测过拟合 | 策略在训练数据上过度优化 | 极高（最常见） | 中 |
| 交易成本忽略 | 未考虑佣金、滑点和市场冲击 | 高（Sharpe 降 50%+） | 低 |
| 制度转换盲区 | 策略在单一市场制度下测试 | 高（实盘可能崩溃） | 高 |

这五类偏差与本综述其他方向的具体关切一一对应：前瞻性偏差 ↔ Hubble 的 LLM 时间泄漏；交易成本 ↔ MACE 的市场冲击建模、From Hypotheses to Factors 的 5bp 成本敏感性；制度转换 ↔ Alpha-R1 的 regime 语义门控、AlphaCrafter 的 Screener；回测过拟合 ↔ MCTS-Alpha 的 Overfitting Risk 维度、AlphaForge 的实盘验证。

## 方向六：文本信号与因子工程

本方向的共同命题是：数据侧的扩展与工程化。MultiFactor 覆盖从因子构建、偏差校正、计算加速到横截面组合优化的完整机器学习流水线（不依赖 LLM 生成因子），为各类 LLM 挖掘方法提供了「因子入库之后」的体系参照；From Text to Alpha 则展示 LLM 对财报披露文本的细粒度语义追踪可直接转化为可交易的横截面信号。

### MultiFactor · arXiv 2507.07107

**论文**：Machine Learning Enhanced Multi-Factor Quantitative Trading: A Cross-Sectional Portfolio Optimization Approach with Bias Correction。

**背景与研究目的**：传统因子投资（如 Fama-French 三因子 / 五因子模型）已难以满足日益复杂的市场需求；基于 Alpha101 扩展与专有微观结构信号的现代多因子体系面临两大核心瓶颈：

- 计算瓶颈：实时处理 500–1000 个因子的大规模因子库对计算资源要求极高，传统 pandas CPU 运算难以支撑；
- 系统性偏差：原始因子往往隐含对市值、行业等系统性风险因素的无意暴露，导致「因子拥挤」与非预期的风险集中。

研究核心问题是：如何在高维因子空间中既保持预测能力，又消除隐含的系统性偏差，并以可扩展的计算架构实现实时交易。

**方法**（六大模块）：

- 多源因子构建：以 Alpha101 为基石，通过变化回看窗口（5–252 个交易日）、平滑参数与截面定义扩展至 300–400 个因子族；开发捕捉大盘股分布动态、波动率区制与截面动量 / 反转的专有因子；经 IC、IR 与因子衰减分析将 1000+ 候选筛选至 500–800 个；
- 偏差校正与中性化（核心创新）：行业中性化（截面回归去除行业虚拟变量影响）、市值中性化（对数线性及二次项调整捕捉非线性规模效应）、自适应中性化强度（中性化参数随市场波动率区制动态调整，高波动时期自动增强校正力度）；
- PyTorch 计算加速：滚动窗口重构为一维卷积（Rolling → Conv1D）实现 GPU 并行，截面排序用双 argsort 并行完成，EWMA 递归原地更新，分块处理配合智能缓存防止显存溢出，对 pandas 实现 18–42 倍加速；
- 机器学习模型：XGBoost、LightGBM、Random Forest；2–6 层 DNN（残差连接 + 批量归一化）；Transformer（4–16 个注意力头，探索绝对与相对位置编码）；
- GBM 数据增强：以几何布朗运动随机微分方程生成合成价格路径：

$$dS_t = \mu S_t dt + \sigma S_t dW_t$$

经 Euler-Maruyama 离散化并以最大似然估计校准参数，扩充训练集；

- 横截面组合优化：MOSEK 求解多目标问题（预测收益 − 风险惩罚 − 交易成本），约束包括市场中性（权重和为零）、行业中性、仓位上限与杠杆率限制；风险模型采用多因子分解 $\Sigma = B\Omega B^{\top} + \Delta$（因子协方差矩阵指数加权动态更新），并引入正则化与热启动提升数值稳定性。

**实验设置**：中国 A 股 2010 年 1 月至 2024 年 12 月，覆盖沪深两市 4000+ 只股票；训练集 2010–2020，验证集 2020–2021，测试集 2021–2024（纯样本外，含 COVID-19 冲击与监管政策变化）；经 survivor bias 校正、分红拆股调整与异常值检测。

**核心结果**：中性化前后对比：

| 指标 | 原始因子 | 中性化后 | 提升幅度 |
| --- | --- | --- | --- |
| 平均 IC | 0.023 | 0.041 | +78% |
| IC 标准差 | 0.156 | 0.089 | −43% |
| 信息比率（IR） | 0.147 | 0.461 | +214% |
| IC 正比率 | 54.2% | 67.8% | +13.6% |

模型性能对比（2021–2024 测试期，Transformer 最优）：

| 模型 | 预测相关性 | 夏普比率 | 年化收益 |
| --- | --- | --- | --- |
| XGBoost | 0.087 | 1.82 | 18.3% |
| LightGBM | 0.091 | 1.89 | 19.1% |
| DNN | 0.094 | 1.95 | 19.7% |
| Transformer | 0.102 | 2.01 | 20.4% |

组合层面：完整策略在测试期实现年化收益 20.4%、夏普比率 2.01、最大回撤低于 8%；横截面市场中性定位有效消除系统性市场风险，策略表现与整体市场方向无关；在 COVID-19 冲击及恢复期保持一致表现。

**主要结论**：偏差校正是因子稳定性的基石——行业与市值中性化不仅未削弱信号，反而将平均 IC 提升近 80%，证明系统性去除非预期暴露对策略鲁棒性至关重要；横截面方法优于时序方法——相对收益预测自然对冲市场风险，利润来源于选股能力而非市场择时；Transformer 架构在金融时序建模中表现卓越，自注意力有效捕捉因子有效性的区制依赖交互；计算加速使实时大规模因子处理成为现实。

**关键概念通俗解释**：

- **截面中性化**（Cross-Sectional Neutralization）：想象评选「最努力的学生」，若直接按考试成绩排名，选出的可能是「家境最好、补习班最多」的学生——这就是规模偏差。中性化相当于在每个班级内部分别排名，先去掉「班级」（行业）和「家境」（市值）的影响，再看谁真正进步最快。自适应中性化更进一步：当市场波动剧烈（如股灾）时自动加强「去偏差」力度，避免极端行情导致因子失效。
- **几何布朗运动**（GBM）数据增强：金融数据的痛点是「历史不会简单重复」——只有一段真实历史，却要预测未来。GBM 数据增强像给历史数据「做克隆」：根据历史波动率与趋势参数，用随机过程生成成千上万条「平行宇宙」中的股价路径；合成数据保持与真实数据相似的统计特性（如波动聚集），却能显著扩充训练集，帮助模型学习更泛化的模式。
- **横截面组合优化 vs 时序预测**：传统方法试图预测「明天大盘涨多少、某只股票涨多少」（绝对收益）；横截面方法换个思路：不问「涨不涨」，只问「哪只涨得更多」。做多排名靠前的股票、做空排名靠后的，即使市场整体下跌，只要排名关系正确，策略仍然盈利——相当于把「预测天气」转化为「预测今天谁比谁更热」，天然规避判断市场方向的困难。
- **因子 IC 与 IR**：IC（信息系数）是因子值与未来收益的相关系数，衡量「因子预测准不准」；IR（信息比率）是平均 IC 除以 IC 波动率，衡量「因子稳不稳」。一个因子可能偶尔 IC 很高但大部分时候失效；IR 高意味着预测能力稳定可靠。论文将 IR 从 0.147 提升至 0.461，相当于可靠性提升两倍多。

**优点**：系统性框架整合（因子工程、偏差校正、计算加速、模型集成、组合优化五位一体）；偏差校正机制扎实（IC 从 0.023 到 0.041 的实证极具说服力）；PyTorch tensor 化改造对从业者有直接参考价值（18–42 倍加速意味着半小时的因子计算可在分钟级完成）；验证严谨（walk-forward、纯样本外测试、含交易成本的净收益）；结果可解释（因子暴露分析、风格归因与区制分析验证收益来源于预期 alpha 而非风险暴露）。

**缺点**：仅针对中国 A 股且未区分板块差异，结论外推存疑；每日重平衡结合复杂约束在实盘中的滑点与冲击成本可能被低估；专有微观结构因子的构建逻辑未充分披露、可复现性受限；Transformer 的经济含义阐释不足；年化 20.4% 与夏普 2.0+ 在 A 股量化属于顶尖水平，论文未充分讨论过拟合风险与策略容量限制。

**后续方向**：跨市场验证与迁移学习（美股、港股、加密货币）；另类数据融合（卫星图像、供应链、社交媒体情绪、ESG）；区制感知模型（显式建模市场区制并动态切换权重）；多资产类别扩展（债券、商品、外汇及衍生品）；因果推断与反事实分析（双重差分、工具变量）；强化学习组合优化（替代二次规划求解器，适应复杂非凸约束）；策略容量与流动性风险分析。

### From Text to Alpha · arXiv 2510.03195

**论文**：From Text to Alpha: Can LLMs Track Evolving Signals in Corporate Disclosures?

**背景与研究目的**：传统 NLP 量化方法（NER、情感分类、词典匹配）能从企业披露文本提取预测信号，但存在根本局限：擅长识别「说了什么」（如「收入增长」），却难以捕捉「怎么说」——丰富的语义细节与上下文限定词。例如「北美云业务收入」与「总收入」在 NER 中可能被等同标记为「收入」，丢失关键限定；同一概念在不同季度以不同措辞表达时（如「销售增长」与「营收提升」），关键词匹配会误判为企业「换了话题」。本文的核心问题是：LLM 能否有效追踪企业披露中随时间演变的语义信号并预测异常收益？作者聚焦「Moving Targets」（移动目标）现象作为测试场景。

**核心概念**：Moving Targets——由 Cohen and Nguyen (2024) 提出，指上市公司在财报电话会议中策略性地改变其强调的业绩指标——当销售增长放缓时，管理层可能转而强调成本节约或战略投资。该现象被证明具有预测未来股票收益的信息含量：指标转移越剧烈，未来收益越低。原始方法使用 spaCy NER 提取指标，并经规则字符串匹配跨季度比较。原始 MT 分数定义为：

$$MT_i = \frac{\sum (\text{Missing Metrics}_i \mid \text{Metrics}_{i-4})}{\sum \text{Metrics}_{i-4}}$$

其中 $i-4$ 表示去年同期（如 2024Q1 与 2023Q1 对比）。

**方法**（「LLM as Extractor, Embedding as Ruler」框架）：

- Extractor（Gemini-2.5-Pro）：输入完整财报电话会议记录（JSON 对话格式），区分管理层陈述（presentation）与分析师问答（analyst_qa），提取短名词短语形式的业绩指标集合 $T_i = \{T_{i,1}, \ldots, T_{i,N_i}\}$；去除数字、单位、货币与百分比符号，季度结果前缀为「Quarterly」、财年结果前缀为「Yearly」，并对近似重复项去重。与 NER 的区别在于 LLM 能捕捉复杂短语中的指标并保留上下文限定词（提取「北美云业务收入」而非仅「收入」）；
- Ruler（text-embedding-3-large）：将指标映射到共享语义嵌入空间，以余弦相似度衡量语义距离，解决「同一指标不同措辞」的匹配问题。对每个前期指标 $T_{j,n_j}$，先计算其与所有当期指标的最大余弦相似度：

$$\hat{S}_{n_j} = \max_{n_i} \cos(E_{i,n_i}, E_{j,n_j})$$

再应用分段线性阈值函数 $h(\cdot)$ 抑制噪声：

$$S_{n_j} = h(\hat{S}_{n_j}) = \begin{cases} 0 & \text{if } \hat{S}_{n_j} \leq \alpha \\ \frac{\hat{S}_{n_j} - \alpha}{\beta - \alpha} & \text{if } \alpha < \hat{S}_{n_j} < \beta \\ 1 & \text{if } \hat{S}_{n_j} \geq \beta \end{cases}$$

其中 $\alpha = 0.4$、$\beta = 0.6$（以 0.2 间隔的网格搜索选定）。最终 LLM 版 MT 分数为：

$$MT_i = 1 - \frac{1}{N_j}\sum_{n_j=1}^{N_j} S_{n_j}$$

当 $S_{n_j} \approx 1$ 时指标被保留、$S_{n_j} \approx 0$ 时被丢弃，与原始定义保持一致。

**评估协议**：采用实证金融学标准方法——组合测试（按最新 MT 分数将股票分为五等分，Q1 最低、Q5 最高，构建等权组合并计算 Q5−Q1 收益差，以 Fama-French 三因子与五因子模型计算风险调整后 alpha）与 Fama-MacBeth 横截面回归（每月将个股次月收益对 MT 分数及控制变量回归，控制变量含 Log(Size)、Log(BM)、Ret(-1,0)、Ret(-12,-1)，跨时间平均月度系数检验显著性）。

**数据**：S&P 100 成分股，2010 年 1 月至 2024 年 12 月；5615 个公司-季度观测、16675 个收益观测；聚焦 S&P 100 的原因是 LLM 提取的计算成本较高，需控制实验规模。

**定性发现**：LLM 提取的指标质量显著优于 NER。高频缺失目标对比：

| 排名 | NER 方法（高频缺失目标） | 频率 | LLM 方法（高频缺失目标） | 频率 |
| --- | --- | --- | --- | --- |
| 1 | the % | 4,460 | market share | 706 |
| 2 | a % increase | 3,845 | share repurchases | 589 |
| 3 | the range | 3,474 | revenue growth | 582 |
| 4 | % growth | 3,456 | pricing | 562 |
| 5 | q3 | 3,006 | cash flow | 535 |

NER 提取的主要是表面模式（「the %」「a % increase」「q3」），缺乏实质业务含义；LLM 提取的是具体业务指标（market share、revenue growth、cash flow 等），与业绩指标的定义高度吻合。个案验证：在 PepsiCo 2011Q4 财报电话会议中，NER 仅提取出 Management 与 dividends，遗漏关键财务指标；LLM 正确识别了 cash flow、operating cash flow、share repurchases 与 dividends。

**定量结果**：组合测试（日历时间组合收益）：

| 方法 | 指标 | Q1（低 MT） | Q5（高 MT） | Q5−Q1 |
| --- | --- | --- | --- | --- |
| NER 基线 | 超额收益 | 1.56%\*\*\* | 1.35%\*\*\* | −0.31%（t = −1.48） |
| NER 基线 | 3 因子 alpha | 0.47%\*\*\* | 0.39%\*\* | −0.18%（t = −0.89） |
| NER 基线 | 5 因子 alpha | 0.45%\*\*\* | 0.41%\*\* | −0.14%（t = −0.70） |
| LLM 方法 | 超额收益 | 1.48%\*\*\* | 1.17%\*\*\* | −0.41%（t = −2.08） |
| LLM 方法 | 3 因子 alpha | 0.56%\*\*\* | 0.18% | −0.48%（t = −2.40） |
| LLM 方法 | 5 因子 alpha | 0.55%\*\*\* | 0.13% | −0.52%（t = −2.55） |

LLM 方法的 Q5−Q1 价差在超额收益、3 因子与 5 因子 alpha 上均达到 5% 显著性水平，而 NER 基线在所有测试中均不显著。Fama-MacBeth 回归：

| 方法 | MT 分数系数 | t 统计量 | 含义 |
| --- | --- | --- | --- |
| NER 基线 | +0.0107 | 1.10 | 不显著，无可靠预测关系 |
| LLM 方法 | −0.0370 | 约 −1.95 | 10% 水平显著：指标转移越多，未来收益越低 |

（注：论文原文表述 LLM 方法在 10% 水平显著、NER 方法不显著；LLM 系数 −0.0370 对应的 t 统计量约为 −1.95，接近 10% 显著性边界。）

**主要结论**：LLM 能有效追踪企业披露中的演变信号——在 moving targets 任务上，LLM 方法的预测能力是 NER 基线的两倍以上（5 因子 alpha：−0.52% 对 −0.14%）；收益来源于语义理解的深度——LLM 保留上下文限定词、区分语义相关但实质不同的指标（如 Total revenue 与 Blackwell revenue），过滤非指标术语（如 NER 误提取的「the %」「q3」），并以 Embedding 相似度识别不同措辞表达的同一概念；框架具有可移植性——方法论可推广至年报、股东信等其他企业披露文本。

**关键概念通俗解释**：

- **Moving Targets**（移动目标）：想象一个朋友每次见面热衷的话题都不一样——上次夸「工资涨了」，这次改说「副业收入多了」，下次又说「投资收益不错」，你会隐约觉得他是不是主业出了问题才不断换话题。上市公司若突然不再提去年强调的核心指标（如「用户增长」），转而强调别的指标（如「利润率改善」），可能是在「转移视线」。研究表明这类「换话题」越频繁的公司未来股价表现越差——本质上是从管理层话语策略中识别信号衰减与注意力操控。
- **LLM as Extractor, Embedding as Ruler**：Extractor（分拣员）——传统 NER 像只会按固定名单分拣的机器人，名单上有「收入」才捡出来；LLM 则像有经验的分析师，能读懂上下文，知道「北美云业务收入」是需要记录的指标而「Q3」只是时间标签。Ruler（柔性尺子）——字符串匹配像一把刚性尺子，只有完全一样的词才算匹配；Embedding 相似度像一把智能尺子，能判断「销售增长」和「营收提升」本质上在说同一件事。
- **分段线性阈值函数**：原始余弦相似度是 0 到 1 之间的连续值，0.55 的相似度到底算「同一个指标」还是「不同指标」？作者设计三段式处理：低于 0.4 直接视为不同（映射为 0），高于 0.6 直接视为相同（映射为 1），0.4–0.6 之间线性过渡（模糊地带按比例计分）——如同老师判卷，90 分以上算 A、60 分以下算 D、中间按比例给 B 或 C，避免「非黑即白」的僵硬判断。

**优点**：问题定义清晰且具金融意义（有明确的理论支撑与可量化的基准，LLM 改进的边际贡献易于评估）；方法论简洁优雅（两个可独立优化的模块，避免端到端黑箱）；实证结果强劲且一致（两种标准协议下均显著优于基线）；定性分析深入（高频缺失目标对比表与个案图示清晰展示优势来源）；控制严格（Fama-MacBeth 回归纳入规模、账面市值比、动量等经典控制变量）。

**缺点**：样本仅覆盖 S&P 100 大公司，而 moving targets 现象在中小公司可能更显著，外推性受限；使用 Gemini-2.5-Pro 与 text-embedding-3-large 的计算成本远高于 NER + 规则匹配，对机构部署可扩展性构成挑战；未做模型消融（固定单一 LLM 与单一 embedding 模型，无法完全分离「提取器贡献」与「标尺贡献」）；经济机制阐释不足（未深入解释为什么更好的语义追踪带来更强预测）；阈值参数 $\alpha = 0.4$、$\beta = 0.6$ 的选择未报告敏感性分析；Fama-MacBeth 显示的是预测关系而非因果关系，传导机制未探讨。

**后续方向**：扩展至 S&P 500、Russell 3000 乃至中小盘股；系统比较不同 LLM 与 embedding 模型的消融研究；以事件研究法探索 PEAD、分析师修正与机构持仓变化等传导路径；细粒度指标分类（成长性、盈利性、运营效率、ESG 等类型转移的信息含量差异）；时序动态与区制依赖；多语言与跨市场验证；与管理层语气、可读性、情感极性等文本特征融合；实时监测与预警系统；零样本 / 少样本场景优化（prompting 与 RAG）。

## 方向七：多模态金融预测与另类数据

本方向的共同命题是：数据模态的扩展与融合机制设计。数据模态覆盖价格序列、文本、声学、频谱图、宏观指标、链上数据；方法论核心是**从「简单拼接」到「制度感知的动态加权」**——不同模态携带不同的预测信号，融合机制本身成为研究对象。

### SEMF · arXiv 2603.27321

**论文**：SEMF: Spectrogram-Enhanced Multimodal Fusion for Commodity Price Forecasting。作者 Soyeon Park、Doohee Chung、Charmgil Hong。

**核心洞察**：**金融时间序列的频率信息被传统方法系统性忽视**——趋势成分（低频）、波动成分（中频）和噪声成分（高频）携带不同的预测信号。

**方法**：Morlet 小波变换 → 频谱图 → Vision Transformer 提取频率感知特征 → Transformer 编码外生变量 → 双向交叉注意力整合。

**实验与结论**：多个商品预测任务上一致超越 7 个竞争基线。

**优点**：把时序数据当作「图像」处理的频谱视角新颖；双向交叉注意力让频率特征与外生变量互补。**缺点**：仅商品数据验证。

### Uni-FinLLM · arXiv 2601.02677

**论文**：Uni-FinLLM: A Unified Multimodal Large Language Model with Modular Task Heads。作者 Gongao Zhang、Haijiang Zeng、Lu Jiang。

**方法**：共享 Transformer 主干 + 模块化任务头。跨模态注意力 + 多任务优化联合处理金融文本、数值时间序列、基本面和视觉数据。

**实验与结论**：股票方向准确率 67.4%（基线 61.7%）；信用风险 84.1%（基线 79.6%）；宏观预警 82.3%。

**意义**：为下游 LLM Agent 提供 richer 状态表示——交易智能体的输入不再局限于价量序列。

### History Rhymes · arXiv 2511.09754

**论文**：History Rhymes: Macro-Contextual Retrieval for Robust Financial Forecasting。作者 Sarthak Khanna 等。

**核心范式**：**检索增强预测**。将宏观指标和金融新闻情感联合嵌入共享相似空间，实现历史类似时期的因果检索——「当前宏观环境像历史上哪个时期」直接作为预测依据。

**实验与结论**：OOD 测试中 AAPL 实现 PF=1.18 和 Sharpe=0.95；**静态基线在制度转换下崩溃**——检索式方法对 regime change 的鲁棒性是关键卖点（与 Alpha-R1 的 regime 门控、AlphaCrafter 的 Screener 异曲同工，只是粒度在宏观层）。

**局限**：检索质量依赖嵌入空间的质量。

### 声学伪装：反例与警示 · 2026-04

Dungrani & Dungrani（2026-04）的发现是本方向最重要的**反例**：在财报电话会议中，**声学特征的融合反而降低了预测性能**——从 NLP 单独模型的 66.25% 召回率降至融合模型的 47.08%。

**原因**：接受过媒体培训的高管可以通过声音调节隐藏真实认知负荷，使得声学特征引入矛盾噪声。

**警示**：并非所有可获取的数据模态都是有价值的，**需要考虑数据生成过程中的策略性行为**——这与 From Text to Alpha 的 Moving Targets 现象一脉相承：管理层的话语（无论语言内容还是声学特征）本身可能是策略性信号，直接当特征用会被「反向操纵」。

### 模态融合方法论对比

| 论文 | 模态类型 | 融合机制 | 关键创新 | 主要局限 |
| :--- | :--- | :--- | :--- | :--- |
| SEMF | 频谱图+数值 TS | 双向交叉注意力 | 小波频谱+ViT 频率感知 | 仅商品数据验证 |
| Uni-FinLLM | 文本+TS+基本面+视觉 | 跨模态注意力+多任务 | 统一主干+模块化头 | 模块间竞争 |
| History Rhymes | 宏观指标+新闻情感 | 共享嵌入空间+检索 | 因果检索先例时期 | 检索质量依赖嵌入 |
| SBCA | 价格 TS+文本情感 | 跨模态门控融合 | BERT 驱动 Actor-Critic | 门控机制可解释性差 |

### 技术融合趋势

**趋势 1：Multi-Agent + 因子挖掘 → 全栈自动化量化**。未来可能出现「量化工厂」（Quant Factory）概念：持续运行的 Multi-Agent 系统，7×24 不间断挖掘因子、评估有效性、构建组合、执行交易——AlphaCrafter 已经打通因子→筛选→执行的全链路，OOM-RL 则探索用真实资金损失做在线对齐。

**趋势 2：RL + 多模态 → 多感官交易 Agent**。Uni-FinLLM 的多模态状态表示 + MACE 式真实成本环境的 RL 训练，未来可能扩展到链上数据、卫星图像、供应链网络。

**趋势 3：评估基准 → 全领域标准化**。AlphaBench（因子挖掘）、PolyBench（实时预测）、QuantCode-Bench（策略代码）、Nguyen & Pham 框架（多智能体）已分别覆盖四个层面，未来可能出现类似 MLPerf 的「QuantAI-Bench」行业基准。

**趋势 4：防污染与防记忆偏差成为评测共识**。PolyBench 的实时数据防污染、BlindTrade 的匿名化负控制、Hubble 的 LLM 时间泄漏警示——三个工作从不同角度指向同一问题：LLM 的先验知识会污染金融实验的有效性，「防污染设计」正在成为评测与实验的新标准。

### 发表趋势观察

2024–2026 年，LLM × 量化因子工作持续进入主流 venue：

- 顶级 AI 会议：AAAI 2025（AlphaForge）、AAAI 2026（MCTS-Alpha）、NeurIPS 2025（R&D-Agent-Quant）、KDD 2025（AlphaAgent）、ACL Findings 2026（AlphaQuanter）、ICLR 2026（AlphaAgentEvo、AlphaBench）、EMNLP 2025 Findings（SAF）与 System Demos（Alpha-GPT）；
- 金融 AI 专门会议：ICAIF 2025（FactorMAD）；
- 专题 Workshop：NeurIPS 2025 GenAI in Finance（EvoAlpha）、ICLR 2025 Financial AI（AlphaQuant）；
- 仍有大量重要工作首发于 arXiv 等待同行评审：AlphaSAGE、AlphaPROBE、FactorMiner、QuantaAlpha、CogAlpha、AlphaLogics、AlphaCrafter、Hubble、From Hypotheses to Factors、Alpha-R1、MultiFactor、From Text to Alpha。

### 未来值得关注的方向

1. **因果化**：从相关性挖掘转向因果机制发现，增强因子的经济逻辑根基；
2. **多模态融合**：文本（新闻 / 财报）、图像（K 线）、数值（价量）统一推理（MultiFactor 与 From Text to Alpha 的启示）；
3. **轨迹 / 记忆级自进化**：QuantaAlpha、FactorMiner、CogAlpha 已开启，AlphaAgentEvo 开始用 RL 直接训练进化策略，待统一理论框架；
4. **生产安全性**：Hubble 的 AST 沙盒与双通道 RAG 应成为新基准；零崩溃、可审计、形式化验证（程序合成）将成为生产级 LLM-Quant 的必备；
5. **跨市场泛化**：多数工作仍局限于 A 股与美股大盘，新兴市场与衍生品验证不足；From Hypotheses to Factors 提供了可复用的加密市场实证协议模板；
6. **实时化与低延迟**：当前 agentic 框架推理延迟较高，难以满足分钟 / 秒级交易需求——蒸馏与模型压缩值得关注；
7. **因子-模型联合优化**（co-optimization）：R&D-Agent-Quant 开启此方向，QuantaAlpha 等下一代工作可结合；
8. **LLM 时间泄漏**（time leakage）：Hubble 已指出，LLM 预训练语料可能含发现期之后的金融文献——需要时间防火墙微调或更严格的 OOS 协议；
9. **市场逻辑 / 假设作为一等公民**：AlphaLogics 显式建模 market logic 是新方向；未来可能扩展至「假设库 + 因子库 + 模型库」三层结构；
10. **统一评测协议**：AlphaBench 首次系统评测 LLM 的生成 / 评估 / 搜索能力，推动该领域从「论文自报数字」走向可横向比较的基准；
11. **协调协议的系统研究**：CPH 假设（协调 > 模型规模）尚缺严格验证；回声室效应（共享底层 LLM 的 Agent「独立性」是否只是表面现象）与最优 Agent 数量问题待解——CBS 指标提供了量化起点；
12. **交易成本与环境真实性的系统性报告**：MACE 证明成本模型选择能反转 RL 算法排名——社区需要「报告成本模型设定」的最低标准；因子挖掘端同样如此（FactorMiner 未纳入交易成本、Hubble Top 因子换手率 11–37%）；
13. **在线闭环与真实损失对齐**：OOM-RL 的真实资金损失对齐方向高风险高回报，与安全机制（回滚、门禁）的协同设计是关键；与 AReaL 2.0 式「部署即采样」基础设施结合是长期方向；
14. **模态融合的策略性数据问题**：声学伪装研究表明管理层行为会反向利用特征（声音调节隐藏认知负荷）——未来另类数据研究需先建模「数据生成过程的博弈」，再谈融合收益；
15. **可微分/白盒方法**：SNAPO 的伴随方法在可微模拟器中实现 O(1) 梯度——若与市场微观结构仿真结合，可能突破采样式策略梯度的样本效率瓶颈，但需解决 LOB 等离散环境的可微化问题。
10. **统一评测协议**：AlphaBench 首次系统评测 LLM 的生成 / 评估 / 搜索能力，推动该领域从「论文自报数字」走向可横向比较的基准。
