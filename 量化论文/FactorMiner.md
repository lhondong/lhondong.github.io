# FactorMiner

> **FactorMiner: A Self-Evolving Agent with Skills and Experience Memory for Financial Alpha Discovery**
> arXiv 2602.14670，2026

## 摘要

公式化阿尔法因子挖掘是量化投资中一项关键而具有挑战性的任务，其特点是搜索空间巨大，且需要具备领域知识、可解释的信号。然而，随着因子库规模扩大，由于高冗余性，发现新颖信号变得越来越困难。本文提出 FactorMiner，一个轻量且灵活的自进化智能体框架，旨在通过持续的知识积累来驾驭这一复杂格局。FactorMiner 结合了**模块化技能架构**（Modular Skill Architecture），将系统化的金融评估封装为可执行工具，以及**结构化经验记忆**（Experience Memory），将历史挖掘试验提炼为可操作的洞察（成功模式与失败约束）。通过实例化 Ralph Loop 范式——检索（retrieve）、生成（generate）、评估（evaluate）、提炼（distill）——FactorMiner 迭代地利用记忆先验来引导探索，在跨多个数据集和市场的多样化资产上减少冗余搜索，同时聚焦于有前景的方向。实验表明，FactorMiner 能够构建一个具有竞争力表现的高质量因子库，并在因子库规模扩大时保持低冗余，为在"相关性红海"（Correlation Red Sea）约束下可扩展地发现可解释公式化阿尔法因子提供了一种实用方法。

## Introduction

公式化阿尔法因子是量化交易和投资组合构建的核心。与端到端的神经网络方法不同，公式化因子具有显式的数学表达式，能够实现人工审计和跨市场机制的组合泛化。然而，自动化的因子发现面临三大根本挑战：

1. **巨大的搜索复杂性**：公式化表达式的空间随算子组合和参数数量呈组合爆炸式增长；
2. **知识积累匮乏**：传统的搜索方法（遗传编程、强化学习）无法在探索会话之间保留和复用洞察，导致重复试验；
3. **可解释性约束**：金融从业者需要透明、可审计的公式，并具备显式的金融逻辑以满足合规和风险管理要求。

### 相关工作

- **Alpha101 (Classic)**：Kakushadze 提出的 101 个手工公式化阿尔法因子，以及 Alpha191 扩展的 191 个公式。这些经典方法局限于日频数据，且其经济可解释性对于复杂嵌套结构而言仍然不透明；高频市场目前缺乏可比的系统化因子库；
- **遗传编程（GP）**：如 GPLearn，将因子公式表示为可执行程序，通过交叉和变异进行进化。但 vanilla GP 探索表达式空间的效率低下、收敛缓慢，且语义引导有限——遗传算子主要作用于程序语法而非程序行为，且缺乏显式、持续地复用跨会话结构性知识的机制；
- **强化学习**：如 AlphaAgent，通过将评估指标（IC/ICIR）作为奖励来导航公式化因子表达式的离散空间，但往往以大量的训练开销和重复评估为代价，且难以解释；
- **LLM/神经驱动框架**：如 AlphaForge，利用大语言模型生成和优化公式化因子。尽管具有探索策略来减轻衰减和冗余，但仍面临显式且持续复用结构性知识模式的挑战；随着因子库增长和冗余/相关性约束收紧，探索变得越来越重复。

核心假设：**因子挖掘智能体应当像人类专家一样积累经验——记住哪些模式有效、哪些方向是死胡同，并在后续探索中利用这些结构化知识来引导搜索，而非每次都从零开始随机探索**。通过将挖掘过程形式化为一个带有经验记忆的序列决策任务，智能体可以在"相关性红海"中持续进化其搜索策略，从而在保持因子库低冗余的同时发现高质量、多样化的阿尔法信号。

## 方法设计

FactorMiner 的核心是名为 **Ralph Loop** 的迭代自进化发现范式，包含四个关键步骤：检索（Retrieve）、生成（Generate）、评估（Evaluate）、提炼（Distill）。输入为市场数据张量 $\mathcal{D} \in \mathbb{R}^{M \times T \times F}$（$M$ 个资产、$T$ 个时间步、$F$ 个特征）、算子库 $\Omega$、目标因子库规模 $K$；输出为高质量、低冗余的因子库 $\mathcal{L}$。

### Pipeline

**步骤 1：记忆检索**。智能体从经验记忆 $\mathcal{M}$ 中检索与当前因子库相关的上下文依赖记忆信号：$m_t = R(\mathcal{M}, \mathcal{L}_t)$。记忆以紧凑的自然语言模板存储（"推荐方向"和"禁区"），并通过匹配当前因子库诊断和近期拒绝原因来检索。

**步骤 2：引导生成**。LLM 智能体根据检索到的记忆先验 $m_t$，从算子库 $\Omega$ 中采样一批候选因子公式 $C \sim \pi(\alpha \mid m_t)$。算子库包含 60+ 个金融算子（如 TsRank、Rsquare、Delay、CsRank 等），参数化以支持多市场配置。

**步骤 3：多阶段评估**。对候选因子进行从粗到细的四阶段筛选，平衡效率与准确性：

- **Stage 1（快速 IC 筛选）**：在少量资产子集上计算 IC，仅保留 $|\text{IC}| \geq \tau_{\text{IC}}$ 的候选；
- **Stage 2（相关性检查）**：检查候选与现有因子库的相关性，仅保留 $\max_{g \in \mathcal{L}} |\rho(\alpha, g)| < \theta$ 的候选；
- **Stage 2.5（替换检查）**：若候选因相关性被拒，但满足高质量条件（IC $\geq 0.10$ 且 IC $\geq 1.3 \times \text{IC}(g)$ 且仅与一个现有因子相关），则替换该现有因子；
- **Stage 3（批次内去重）**：对通过前序阶段的候选进行批次内相关性去重（$\rho < \theta$）；
- **Stage 4（完整验证）**：在完整资产集上进行全面验证，收集评估轨迹 $\tau$。

**步骤 4：因子库更新**。$\mathcal{L} \leftarrow \mathcal{L} \cup C_{\text{admitted}}$。

**步骤 5：记忆进化**。将本次迭代的评估轨迹提炼并整合进经验记忆：$\mathcal{M} \leftarrow E(\mathcal{M}, F(\tau))$，其中 $F$ 是形成算子（提炼成功/失败模式），$E$ 是进化算子（整合、去重、淘汰低效用信息）。循环直至 $|\mathcal{L}| \geq K$ 或预算耗尽。

### 模块结构

**（1）经验记忆 $\mathcal{M}$**：存储历史挖掘会话中的成功模式 $\mathcal{P}_{\text{succ}}$ 和禁区 $\mathcal{P}_{\text{fail}}$，包含三类内容：

- **挖掘状态 $\mathcal{S}$**：追踪因子库的全局演化，包括当前库大小、近期准入日志、饱和指标（如哪些逻辑领域已过度拥挤）；
- **结构性经验 $\mathcal{P}$**：推荐方向（从近期批次中提炼的高成功率逻辑模板，如"使用 Skew/Kurt 进行环境切换的高阶矩策略"）与禁区（被识别为"红海"的区域——与现有因子库高度相关的因子族，如简单 VWAP 偏差变体、标准化收益率、简单 Delta 反转）；
- **策略洞察 $\mathcal{I}$**：从挖掘过程中学习的高层次经验（如"非线性组合策略显著优于线性组合"、"高阶矩在高频数据中的不稳定性"）。

**（2）智能体技能**：采用工具增强范式，分层组合设计——算子层（60+ 金融算子库，GPU 加速后端）、验证流水线（标准化多阶段因子评估协议 check_ic → check_correlation → admit）。三大优势：防止计算幻觉、跨领域可迁移（通过配置文件切换市场）、独立优化（执行后端与 LLM 推理模型解耦）。

**（3）因子库 $\mathcal{L}$**：动态增长的因子集合，在增长过程中维持正交性约束。智能体从全局库视角做出挖掘决策：考虑候选因子如何补充现有库，而非孤立优化单个因子。

**三大记忆算子**：

- **形成算子（Formation）**：$\mathcal{M}_{t+1}^{\text{form}} = F(\mathcal{M}_t, \tau_t)$，从原始评估轨迹中提取信息性产物，将原始数据提炼为符号模式；
- **进化算子（Evolution）**：$\mathcal{M}_{t+1} = E(\mathcal{M}_t, \mathcal{M}_{t+1}^{\text{form}})$，整合新形成的记忆候选，合并冗余条目，丢弃低效用信息。工作示例：若某 VWAP 偏差变体被准入但显示 0.82 的相关性，则将其重新归类为 $P_{\text{fail}}$ 以防止未来冗余探索；
- **检索算子（Retrieval）**：$m_t = R(\mathcal{M}_t, \mathcal{L}_t)$，在因子生成阶段检索上下文依赖的记忆信号。

**优化目标（正交因子库合成）**。

$$
\mathcal{L}^* = \arg\max_{\mathcal{L} \subset \mathcal{P}} \sum_{\alpha \in \mathcal{L}} \Phi(\alpha) \quad \text{s.t.} \quad \forall \alpha_i \neq \alpha_j \in \mathcal{L}: |\rho(\alpha_i, \alpha_j)| < \theta
$$

其中 $\mathcal{P}$ 为可构造程序的无限空间，$\Phi(\cdot)$ 为适应度指标（IC、ICIR）。

## 实现与结果

### 实验设置

- **数据集**：A 股 CSI500、CSI1000、HS300 成分股，使用 10 分钟 K 线（训练期 2024-Q1 至 Q4，测试期 2025 全年，总计超过 2500 万数据点）；加密货币 Binance 64 个主要资产的 10 分钟 K 线（同期划分）。预测目标为下一期 10 分钟开盘到收盘的价格变化比率；
- **基线**：Alpha101 (Classic)、Alpha101 (Adapted)、Random Formula Exploration (RF)、GPLearn、AlphaForge、AlphaAgent；
- **评估指标**：IC、ICIR、Avg $|\rho|$（因子库内平均两两绝对相关性）；因子组合（等权 EW、IC 加权 ICW）；因子选择（Lasso、XGBoost，2024 年训练、2025 年测试）；
- **关键设置**：所有方法共享相同的算子库、数据、评估/准入协议；LLM 使用 Gemini 3.0 Flash；FactorMiner 使用 40-worker 多进程池；默认准入阈值 IC $\geq 0.04$、相关性 $\theta = 0.5$（A 股）；消融实验阈值 IC $> 0.02$、$\theta = 0.85$。

### 主结果：样本外表现（Top-40 因子，2025 年测试）

| 数据集 | 方法 | IC (%) | ICIR | Avg \rho |
| --- | --- | --- | --- | --- |
| CSI500 | RF | 2.68 | 0.25 | 0.13 |
| | Alpha101 (Classic) | 4.49 | 0.42 | 0.19 |
| | Alpha101 (Adapted) | 5.06 | 0.43 | 0.21 |
| | GPLearn | 6.04 | 0.43 | 0.44 |
| | AlphaForge | 4.48 | 0.38 | 0.36 |
| | AlphaAgent | 5.90 | 0.46 | 0.32 |
| | **FactorMiner** | **8.25** | **0.77** | **0.31** |
| CSI1000 | **FactorMiner** | **7.78** | **0.76** | **0.30** |
| HS300 | **FactorMiner** | **7.46** | **0.38** | **0.31** |
| Crypto | **FactorMiner** | **3.82** | **0.28** | **0.25** |

FactorMiner 的 IC 几乎达到次优方法的 1.5–2 倍；冗余度显著低于 GPLearn 的 0.44–0.45。

### 因子组合与下游任务

- 等权组合 IC：FactorMiner 14.95% vs Alpha101 (Classic) 10.85% vs AlphaAgent 10.99%；
- IC 加权组合 ICIR：FactorMiner 1.31 vs Alpha101 (Adapted) 1.13 vs AlphaAgent 0.99；XGBoost 因子选择 ICIR 1.29；
- Crypto 等权组合 IC 9.48%、ICIR 0.62，显示因子捕捉了跨资产不变的价格-成交量动态；
- 发布 110 个 A 股高频因子的开放公式化因子库，平均绝对两两相关性 Avg $|\rho|$ = 0.203。

### 记忆消融实验

"Have Memory" 产生 96 个高质量候选（60.0% 产率），"No Memory" 仅产生 32 个（20.0% 产率），产量提升 3 倍。记忆变体的冗余拒绝率为 55.2%，无记忆变体为 43.8%——记忆不仅提高产率，还使系统更积极地过滤冗余。

### 计算效率

- 算子级 GPU 后端相比 Pandas 实现加速 8–59 倍，相比 C 后端加速 2–13 倍（方法章节口径：核心算子 PyTorch/CuPy 较 Pandas 获 6–26 倍加速）；TsRank 算子：1843 ms（Pandas）→ 393 ms（C）→ 31 ms（GPU）；即使高度优化的 C 实现平均仍比 GPU 慢 5.4 倍；
- 因子级端到端：排名密集型因子实现 23–27 倍加速；评估 1000 个候选因子约 6 分钟（Pandas 约 70 分钟）。

### 后续方向

1. 交易成本感知挖掘：将滑点、市场冲击、手续费纳入因子评估和组合构建；
2. 更广泛资产类别与频率扩展：期权、期货、外汇、tick 级超高频数据；
3. 记忆的可解释性与人工审计：开发可视化工具让人类专家审计经验记忆，实现人机协同进化；
4. 因子动态衰减监测：当记忆中的成功模式在样本外持续失效时自动触发记忆重置或权重调整；
5. 端到端因子组合优化：将因子挖掘与组合构建联合优化；
6. 对抗性鲁棒性测试：评估因子库在极端市场事件中的稳健性。

## 总结

让 AI 像资深量化研究员一样积累经验、避开弯路、持续进化。

1. **读取记忆**：从过往挖掘记录中提取"成功经验"和"失败禁区"；
2. **生成候选**：大语言模型根据记忆提示，用金融算子组合出新因子公式；
3. **四层筛选**：快速算 IC 淘汰弱信号 → 查相关性去冗余 → 高质量替换机制 → 完整验证；
4. **入库积累**：通过筛选的因子加入因子库，本次探索的成败记录更新到记忆中；
5. **循环进化**：带着更新后的记忆进入下一轮，越挖越聪明、越挖越精准。
